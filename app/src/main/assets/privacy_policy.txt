Privacy Policy for LeFauxPass

Last updated: September 20, 2026

LeFauxPass is an unofficial Android application. This policy describes the data behavior visible in the current source code.

Information Stored on the Device
================================

LeFauxPass stores a ticket expiration timestamp locally in Android SharedPreferences. The app does not contain an account system, advertising SDK, analytics SDK, or project-operated backend, and the current source does not send that stored expiration timestamp to the developer.

Android backup is enabled in the application manifest. Depending on the Android version, device settings, and platform backup behavior, locally stored app data may be included in Android backup or device-transfer systems.

Network Access
==============

LeFauxPass connects to GitHub to check for application updates and to download APK release assets. Those requests are made to GitHub infrastructure, so GitHub may receive ordinary network metadata associated with a request, such as an IP address and request headers, according to GitHub's own policies.

LeFauxPass does not operate a separate server that receives these update requests.

Permissions
===========

The application currently declares:

* INTERNET — used to query GitHub releases and download APK updates.
* REQUEST_INSTALL_PACKAGES — used so the app can hand a downloaded APK to Android's package installer.

Downloaded update APKs are written to the application's cache directory before installation is requested.

Third-Party Services
====================

The update feature uses GitHub's public API and release hosting. Use of GitHub infrastructure is subject to GitHub's applicable privacy terms and policies.

Changes to this Privacy Policy
==============================

This policy may be updated when application behavior changes. The version bundled with the app should be kept synchronized with networking, storage, permission, analytics, and update behavior.
